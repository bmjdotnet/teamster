# startup-min

**Loads at:** interview time (session start, before mode is chosen).

**Contents:** intentionally none of the protocol/lesson corpus.

## Why this pack is empty

The interview is procedural — mode selection (solo vs. team), outcome
creation, tag application — and none of that requires reading eight-rules,
field-guide, muster-guide, execution-loop, or rubrics. Those documents
describe how to *run* a team or execute reviewed work; the interview
happens before either of those things is true.

This is the startup-cost-sensitive path (measured −61% at team interview
per the optimization plan). Keeping this pack empty is not an oversight —
it's the mechanism that produces the saving. If a future need surfaces for
some genuinely interview-time reference material, add it here deliberately
and re-measure; don't let this pack accrete content by default.

Intake mechanics themselves (interview flow, mode selection, outcome
creation, tag application) live in `session-protocol.md` (single canonical
copy, shared by `start`, `bootstrap`, and `solo` — not a reference pack,
part of the skill body itself).
